

# ba-3char-domains

# 🇧🇦 Generator .ba Troznakovnih Domena (3-Char Domains)

Dobrodošli! Ovaj projekat sadrži bazu generisanih troznakovnih (`3-char`) kombinacija za nacionalnu domenu Bosne i Hercegovine (.ba). 

Troznakovne domene (npr. b2c.ba, kap.ba, nov.ba) su izuzetno kratke, lako se pamte i predstavljaju premium digitalnu imovinu čiji je ukupan broj strogo ograničen.

---

# Analiza i Struktura Troznakovnih .ba Domena (3-Char)

Ovaj projekat predstavlja istraživanje i analizu dostupnosti troznakovnih (`3-char`) kombinacija unutar nacionalne domene Bosne i Hercegovine (.ba). 

Ukupan broj troznakovnih kombinacija je strogo ograničen, što ih čini vrijednim resursom za domaći digitalni ekosistem.

## 📊 Sadržaj repozitorija
* `uzorak_slobodnih_A.txt` - Javno dostupan uzorak slobodnih domena koje počinju na slovo A (informativnog karaktera).
* `uzorak_zauzetih_A.txt` - Javno dostupan uzorak slobodnih domena koje počinju na slovo A (informativnog karaktera).

## 📂 Kompletni skupovi podataka (Full Lists)

2. **Lista ZAUZETIH troznakovnih domena**
